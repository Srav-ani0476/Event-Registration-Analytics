# Requirements Specification

## 1. Project Title
**Event Registration and Participation Analytics System Using MySQL**

## 2. Project Overview
This project is a MySQL-based database system designed to manage participants, organizers, events, registrations, attendance and feedback.

It helps organize event-related data and analyse participation using SQL queries.

## 3. Problem Statement
Managing event information manually can cause duplicate records, inconsistent data and difficulties in tracking registrations and attendance.

This project provides a structured database solution to manage event information efficiently.

## 4. Objectives
- Design a relational database for event management.
- Maintain participant, organizer and event details.
- Manage registrations and attendance.
- Store participant feedback and ratings.
- Retrieve and analyse data using SQL.
- Generate reports using views and stored procedures.
- Perform analytical operations using window functions.

## 5. Project Scope
The project covers:
- Participant and organizer management.
- Event and category management.
- Registration and attendance tracking.
- Feedback management.
- Event participation analysis and reporting.

The implementation focuses on MySQL database operations without a web-based interface.

## 6. Functional Requirements
- Store and retrieve participant and organizer details.
- Maintain event information and categories.
- Record registrations and their statuses.
- Track attendance as Present or Absent.
- Store feedback with ratings between 1 and 5.
- Generate reports and analyse data using SQL.

## 7. Non-Functional Requirements
- **Data Integrity:** Maintain valid records using keys and constraints.
- **Consistency:** Organize related information across tables.
- **Maintainability:** Keep SQL scripts and documentation organized.
- **Reliability:** Prevent invalid data through database constraints.

## 8. Software Requirements
- Operating System: Windows
- Database: MySQL
- Database Tool: MySQL Workbench

## 9. Expected Outcome
A structured relational database that supports event management, registration tracking, attendance monitoring, feedback storage and analytical reporting.

## 10. Conclusion
The project demonstrates relational database design and practical SQL implementation using MySQL.
